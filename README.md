# Personal Portfolio Website

A clean, modern, and responsive personal portfolio website built with HTML, CSS, and JavaScript.

## Features

- Modern and responsive design
- Smooth scrolling navigation
- Skills progress bars with animations
- Project filtering functionality
- Contact form
- Animated elements on scroll
- Mobile-friendly layout

## Structure

```
personal-portfolio/
│
├── index.html              # Main HTML file
├── styles.css              # CSS styles
├── script.js               # JavaScript functionality
├── assets/                 # Directory for assets
│   ├── images/             # Images directory
│   └── resume.pdf          # Your resume in PDF format
└── README.md               # This file
```

## Customization Guide

### 1. Personal Information

Edit the following in `index.html`:

- Your name (replace "Your Name" throughout the document)
- Your profession (currently "Web Developer & Designer")
- Your bio in the About section
- Your contact information (email, phone, location)
- Social media links (GitHub, LinkedIn, Twitter, etc.)

### 2. Skills

Modify the skills section to showcase your actual skills and proficiency levels.

### 3. Projects

Replace the placeholder projects with your own projects:
- Update project titles and descriptions
- Replace project images with screenshots of your work
- Update the technologies used for each project
- Add links to live demos and code repositories

### 4. Resume

Replace the placeholder `resume.pdf` in the assets directory with your actual resume.

### 5. Styling

Customize the website's look and feel by editing `styles.css`:
- Change the color scheme by modifying the CSS variables at the top
- Adjust fonts, spacing, or other style properties

## Usage

Simply open `index.html` in a web browser to view your portfolio.

## Note

The contact form is currently set up for demonstration purposes only. In a real-world scenario, you would need to connect it to a backend service to process form submissions.
